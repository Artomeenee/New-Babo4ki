ЗДРАВСТВУЙТЕ
это отредактированный проект по NetLogo для моего зачёта по моделированию.
Суть: это симуляция природного процесса, при котором бабочки ищут самое высокое место ландшафта местности, где они обитают.

Оригинальный код был взят с какого-то базового сайта по NetLogo, но мне не хватало ползунка, потому что вероятность нахождения бабочкой пластины с характеристикой больше какой-либо величины была фиксированной. К тому же, в код я добавил статистику - какой процент бабочек в реальном времени добрался до самой высокой точки.
